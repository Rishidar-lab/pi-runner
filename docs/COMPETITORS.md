## Competitive Gap Analysis

Based on verified observations, the following gaps exist in the current Pi ecosystem game market:

1. **No dominant endless runner** — RUN FOR PI is the only verified Pi-native endless runner; described as "underdeveloped compared to mainstream mobile titles."
2. **Leaderboards are rare** — FruityPi users explicitly requested one; Slice Of Pi has one; RUN FOR PI's status unverified. Leaderboards are a proven retention mechanic in mainstream runners.
3. **Save/persistence issues** — FruityPi's score-reset complaint is a fixable UX gap.
4. **Ad reward reliability** — FruityPi's inactive watch-ad option shows ad delivery is a known pain point.
5. **Localisation** — No verified Pi ecosystem game explicitly mentions Tamil or South Indian localisation. This is an untapped differentiation.
6. **Cultural theming** — No verified Pi ecosystem game uses South Indian/Tamil cultural themes. Most are generic casual formats.

## Original Concept & Naming Recommendation

### Concept

A polished, culturally-themed endless runner (or runner-adventure hybrid) built for the Pi ecosystem with:
- Tight, responsive gameplay addressing the "frustration" complaints of RUN FOR PI
- Save/persistence done properly
- Optional leaderboard (community-proven demand)
- Tamil/English localisation (untapped market)
- Pi SDK integration for auth, U2A cosmetics, and Pi Ad Network
- Rewarded ads designed as a player benefit (clearly communicated, not income)
- Culturally distinctive art and narrative theming

### Naming Constraints (Pi Network Trademark Rules)

- URL must NOT start with "pi" (e.g., `pi-runner.pinet.com` is not allowed).
- "Pi" in the app name requires a **Trademark Licensing Agreement** from the Pi Foundation.
- Only the forms **"App_Name for Pi"** or **"App_Name on Pi"** are allowed without a separate licensing agreement.
- "Pi Runner" is already taken by multiple unaffiliated products (standalone Android platformer by mxlarscoding — com.pirunner.app; itch.io "PI Runner" by pierporz; Kongregate/Newgrounds "Pi Runner" 2007; "Pi Race"; "Pie Runner"; TI-83 game). None are affiliated with Pi Network.

### Recommended Name Candidates

#### 1. Kurinji Run

- **Meaning:** Kurinji (Kurinji) is the rare blue flower that blooms once every 12 years in the Western Ghats of Tamil Nadu. Symbolises rarity, beauty, and the waiting/reward loop — thematically resonant with an endless runner's "one more try" appeal.
- **Trademark:** No collision found in Pi ecosystem or mainstream gaming.
- **URL:** kurinji-run.pinet.com (does not start with "pi"; no Trademark Licensing Agreement needed).
- **Pi branding form:** "Kurinji Run on Pi" (allowed form).
- **Localisation resonance:** Tamil Pioneers immediately recognise the reference; English-speaking players find it exotic and memorable.

#### 2. Thamizha Dash

- **Meaning:** "Thamizha" is a respectful, poetic Tamil invocation of the Tamil language/culture. "Dash" signals speed and the runner genre.
- **Trademark:** No collision found.
- **URL:** thamizha-dash.pinet.com (does not start with "pi").
- **Pi branding form:** "Thamizha Dash for Pi" (allowed form).
- **Localisation resonance:** Direct Tamil cultural pride signal; clearly differentiated from all existing Pi ecosystem games.

#### 3. Vaanam Dash

- **Meaning:** "Vaanam" means "sky" in Tamil. Evokes upward momentum, aspiration, and open-space running.
- **Trademark:** No collision found.
- **URL:** vaanam-dash.pinet.com (does not start with "pi").
- **Pi branding form:** "Vaanam Dash for Pi" (allowed form).
- **Localisation resonance:** Accessible to Tamil and non-Tamil speakers alike; easy to pronounce.

### Recommendation

**Primary: Kurinji Run** — strongest cultural narrative, inherent "rare reward" symbolism, no collisions, clear differentiation from all verified competitors. Fallback: **Thamizha Dash** if a more explicitly cultural name is preferred.
